# Лабораторная работа №1

Данная лабораторная предназначена для освоение базового синтаксиса HTML и CSS.

## Общая необходимость для подготовки к каждой лабораторной

1. Перейти в папку с заданием:

```bash
cd ./Задание N
```

2. Установить необходимые зависимости:

```bash
npm i
npx puppeteer browsers install chrome
```

3. Каждое задание после выполнения необходимо проверить с помощью команды:

```bash
npm run test
```

### Задание 1

1. Перейти в папку `Задание 1`
2. В файле `src/index.html` внутри `<body>` сделайте страницу следующего вида:

-   Заголовок первого уровня;
-   Заголовок второго уровня;
-   Нумерованный список из трёх элементов, каждый из которых ссылка на какой-то ресурс;

Внутри каждого тега должен содержаться осмысленный текст.

### Задание 2

1. Перейти в папку `Задание 2`
2. В файле `src/App.css` опишите стили для вёрстки из файла `index.html`

- Файл `src/index.html` редактировать нельзя
- Контейнер должен быть шириной `700px` и высотой `300px`
- Элементы - круги `100х100px` (почитайте про свойство border-radius).
- Цвет элементов - `#DAA520`
- Первый и пятый элементы должны быть прижаты к верхнему краю оси Y
- Второй и четвертый должны располагаться посередине по оси Y
- Третий должен находится внизу по оси Y
- Сами элементы должны располагаться по всей оси Х контейнера с одинаковыми промежутками между ними

### Задание 3

1. Перейти в папку `Задание 3`
2. В файле `src/index.html` добавьте на страницу следующие скрипты:

-   Встроенный скрипт, который будет исполнять следующий код:

```javascript
document.body.append('inline');
```

-   Внешний скрипт `src/scripts/sync.js`
-   Внешний скрипт `src/scripts/async.js` с атрибутом async
-   Внешний скрипт `src/scripts/defer.js` с атрибутом defer
